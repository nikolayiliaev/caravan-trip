# 🚐 Caravan Trip - Czech & Austria

אפליקציית ווב PWA לניהול וארגון טיול קראוון לצ'כיה ואוסטריה (13-22 ספטמבר 2026).

## ✨ תכונות

- 📅 **מסלול יומי** - לוח זמנים מפורט ל-10 ימי טיול
- 📋 **רשימת הזמנות** - מעקב אחר הזמנות קמפינגים, כרטיסים ואטרקציות
- 🛒 **רשימת קניות** - רשימה מאורגנת של מוצרים להצטיידות
- 🚐 **מידע קראוון** - פרטים חשובים על הרכב, אגרות ודלק
- 🌧️ **תוכניות גשם** - חלופות מוכנות לכל מזג אוויר
- 🗺️ **מפות ניווט** - קישורים ישירים ל-Google Maps
- 📱 **PWA** - עובד גם בלי אינטרנט, ניתן להתקנה על המכשיר

## 🛠️ טכנולוגיות

- **React** + TypeScript
- **Vite** - כלי בנייה מהיר
- **Tailwind CSS** - עיצוב מודרני וגמיש
- **PWA** - Progressive Web App לעבודה offline

## 🚀 התקנה והרצה

```bash
# התקנת תלויות
npm install

# הרצה בסביבת פיתוח
npm run dev

# בנייה לפריסה
npm run build

# תצוגה מקדימה של הבילד
npm run preview
```

## 🌐 פריסה

האפליקציה מוכנה לפריסה ב-GitHub Pages. להוסיף את שם החשבון שלך ב-`vite.config.ts`:

```typescript
base: '/caravan-trip/'
```

## 📝 עדכון מידע

כל המידע על הטיול נמצא בתיקיית `src/data/`. ניתן לערוך את קבצי ה-JSON לפי הצורך:

- **itinerary.json** - לוח זמנים כללי
- **bookings.json** - הזמנות לביצוע
- **daily-plans.json** - תכנון יומי מפורט
- **shopping.json** - רשימת קניות
- **caravan.json** - פרטי קראוון ואגרות
- **weather-backup.json** - תוכניות חלופיות
- **maps.json** - קישורי מפות

## 📱 שימוש

1. פתח את האפליקציה בדפדפן
2. בחר בתפריט הראשי את הקטגוריה הרצויה

5. האפליקציה תישמר אוטומטית במכשיר ותעבוד גם בלי אינטרנט
